Delegate a self-contained task to a sub-agent that works in its own session and returns a written result. `subagent_type` picks the agent (for example `explore` for read-only research, `general` for multi-step work). Give a complete `prompt` — the sub-agent sees nothing else — and say exactly what it should return. Use a short `description`. Pass `task_id` to continue a previous sub-agent. Do not delegate what one `read`/`grep` call would answer.
